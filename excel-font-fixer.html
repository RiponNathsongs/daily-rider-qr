বাংলা Excel Font Fixer

Upload an Excel workbook, select the cells containing broken Bangla text, preview the correction, and download a repaired copy.

📁 1. Upload Excel file

Supports .xlsx workbooks. Processing happens in your browser; the file is not uploaded to DRQR or Firebase.

🎯 2. Select Sheet and Cells

Examples: E:E selects the used cells in column E; E4:E200 selects a range; E4,E7,E9 selects individual cells. Multiple ranges can be separated by commas. Only text cells are processed; formulas and other cells are left unchanged.

👀 3. Preview original and corrected text

CellOriginalFixed preview

Download creates a separate repaired copy. Your original file is not overwritten. Review the preview before downloading.
