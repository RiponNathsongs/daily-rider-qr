Tools Dashboard

Eight useful tools in one place. QR and barcode creation, ID formatting, rider cost calculations and personal notes—all without changing your DRQR Firebase data.

📷 QR Scanner

Scan a QR code using your device camera. Camera access requires permission and a secure HTTPS page.

If your browser does not support QR detection, use a browser with BarcodeDetector support.

🔳 Custom QR Maker

Create a downloadable QR code for an ID, URL, contact detail or any short text.

🧹 ID Formatter

Clean up IDs by removing extra spaces, converting to uppercase and formatting a list one ID per line.

🏷️ Barcode Generator

Generate a Code 128 barcode for text or a rider ID. Some characters may be rejected by barcode rules.

⛽ Fuel Cost Calculator

Estimate fuel cost for a trip using distance, mileage and fuel price. Results are estimates, not official rates.

💵 Rider Income Calculator

Calculate estimated net income after expenses. Enter your own amounts; values are not uploaded.

📝 Quick Notes

Save short personal notes in this browser only. Notes do not sync to Firebase or other devices.

🌐 Internet Speed Test

Runs a small download test and estimates throughput. Results depend on your connection, browser, and test server; this is not a certified speed test.

The test downloads temporary data from Cloudflare. Avoid running repeatedly on a limited mobile data plan.
